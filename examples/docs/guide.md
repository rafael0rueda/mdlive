# Guide

Opened from a link in the demo. Relative links to markdown files open the file
in Neovim, and the preview follows it.

[Back to the demo](../demo.md)

## Overview

mdlive renders the buffer in your browser while you type.

## Install

```lua
{ "rafael0rueda/mdlive", ft = "markdown", opts = {} }
```

## Usage

Run `:MdLive` in a markdown buffer.
